# Design System & Identité Visuelle INTIMA

## 1. Direction Artistique

INTIMA adopte une direction visuelle haut de gamme, sobre, épurée et rassurante :
- **Atmosphère** : Chaleureuse, premium, respectueuse.
- **Formes** : Rayons doux (16px pour les cartes, 12px pour les boutons, 20px pour les dialogues).
- **Typographie** : Clarté optimale et hiérarchie soignée.
